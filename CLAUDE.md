# eBlocul — сервер

Backend приложения жилого комплекса: NestJS, Prisma, PostgreSQL.

## Где правда

- **Что делает продукт** — комплект документов 2.0 на Drive, вход через «Карту документов». Код — не источник требований.
- **Как устроена система** — архитектура 03: модули, транзакции, задания, авторизация.
- **Как писать код** — `.claude/rules/`. Файлы подгружаются сами по путям, с которыми идёт работа.

Документ и код расходятся — прав документ; о расхождении нужно сказать, а не чинить молча.

## Карта `src/`

`app → modules → core → shared`

- `app/` — только сборка приложения;
- `modules/<модуль>/` — прикладные модули, друг от друга не зависят;
- `core/<модуль>/` — ядро, о прикладных модулях не знает;
- `shared/` — общее без предметной области;
- `generated/` — клиент Prisma, руками не правится.

Внутри модуля пять папок: `domain/`, `ports/`, `application/`, `infrastructure/`, `presentation/`.

## Готово, когда

Проходят `npm run lint`, `npm run typecheck`, `npm test`; при изменении API или базы — ещё `npm run test:e2e`.
`oxlint.json` руками не правится: правка в `scripts/oxlint-config.ts`, затем `npm run lint:config`.

## Всегда

- Комментариев в коде нет.
- Журнал — только через `EventLogger`; в полях только id, числа и значения enum.
- Время и id — только из `Clock` и `Ids`.
- Секреты и персональные данные не попадают в журнал, ответы и `details` ошибок.
- Другой модуль импортируется только через его `index.ts`; чужие таблицы в запросах запрещены.
- Всё, что модулю нужно снаружи, — порт в `ports/`; в `domain/` абстрактных классов для DI нет.
- Доступ проверяет только `authz`, внешние каналы — только `notify`, журнал действий — только `journal`.

## Сначала спросить

- Нужного правила нет — не придумывать своё.
- Новая зависимость в `dependencies`.
- Несовместимое изменение схемы базы: есть ли уже пользователи.
- Проверку нельзя пройти без отключения правила линта или теста.

## Коммиты и PR

Conventional Commits на английском: `feat(tickets): reopen a closed ticket`. Область — имя модуля.
Описание PR — по шаблону `.github/pull_request_template.md`. Claude открывает PR, но не вливает его.
